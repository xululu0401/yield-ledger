# 出成率对账台（yield-ledger）

买一只整鸡、一条整鱼、一整扇排骨或一整条腿回家自己拆，还是直接买分部位的肉？——把「毛重到净料」的**出成率**、不可食损耗、处理成本与分部位市价摊成一本可以复算的账。

体验地址：https://xululu0401.github.io/yield-ledger/

## 这本账算什么

| 量 | 公式 |
|---|---|
| 整只买价 | `B = 毛重 × 毛重单价` |
| 到手总成本 | `C = B + 处理成本` |
| 净重 | `w_i = 毛重 × 出成率_i`（不可食 = 毛重 − Σw_i） |
| 分部位市值 | `V = Σ w_i × 市价_i` |
| **折扣率** | `r = C / V` |
| 分摊成本（相对售价法） | `C_i = C · V_i / V` → 等效单价 = `r × 市价_i` |
| 净料单价 | `C / 净料总重 = r × 按净重加权平均市价` |
| 熟食成本 | `C_i / (w_i × 熟制率_i)` |
| 临界熟制率 | `z* = r × 市价_i / 成品熟食价_i` |
| 盈亏平衡毛重单价 | `(V − P) / W`（含处理成本口径） |
| 回本最少部位数 | 按产值降序累加、首个 ≥ C 的前缀长度 |

## 口径与边界

- 出成率**以毛重为基准**；不可食部分 = 毛重 × (100% − 出成率合计)，不重复计列。
- 联合成本按**相对售价法**分摊，这是会计口径而非唯一正确答案（按重量分摊会得到不同结果）。
- 熟制只按**质量缩水**建模；不建模成分流失、调味料与能源成本。
- 价格、出成率、熟制率、处理成本**全部由使用者填写**，页面不联网、不查行情、不预测价格。
- 不做食品卫生与安全判定；不含运费、税费、包装、冰箱电费与存放损耗。
- 默认数据与 9 个内置场景都是**虚构示例**，不代表任何真实市场分布。
